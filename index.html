System Architecture & Info

On-Premise Deployment Pipeline

PRAGMA is packaged into an isolated Docker container configured for on-premise execution on Oil India Limited CPU server clusters.

[Report Text Ingestion] → [Layer 1: Energy × Barrier Ontology Engine (Fast Path)]
    ├── Clear Match (45%): Instant SIF Verdict + Verbatim Citation
    └── Ambiguous Cases: Escalated to Layer 2
[Layer 2: Fine-Tuned DistilRoBERTa Binary Classifier + Multi-Label IOGP Transformer]
[LIME / spaCy Evidence Extractor] → [Human Reviewer Queue (Accept/Override/Escalate)]
[PostgreSQL + pgvector Engine] → [On-Premise CPU Server (Zero Cloud Dependency)]

Data Source Disclosure & Governance

All field reports evaluated in this prototype environment are synthetic data models derived from public IOGP safety reports and OIL field operational scenarios. No confidential Oil India Limited telemetry is transmitted externally.
